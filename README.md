## How to use

The skills are not publicly distibuted using official libraries and marketplace. You need to install them locally/directly.
Clone the repository and then copy the file.

### Claude

Copy the folder of the skill you want from this repo into  ~/.claude/skills/ (user folder on windows)

Examples:
```
──  .claude/
    └── skills/
        └── requirements-elicitation/
            └── SKILL.md
```
